# Chess with Computer  
A beginner-friendly chess game where you play against an AI with an 850 ELO rating. I built this game in 11th grade to learn machine learning, Python programming.

**Features**  
- Play against an AI with 850 ELO rating  
- Beginner-friendly interface  
- Built-in chess rules and game logic  

**How to Run It**  
1. Install Python 3.x  
2. Install Pygame library:  
   ```sh
   pip install pygame
3. Run Main.py
   ```sh
   python Main.py
